📐 Theory Compendium: Real Numbers & Decimal Comparisons

Real numbers consist of rational numbers (terminating or repeating decimals) and irrational numbers (non-terminating, non-repeating decimals). We evaluate, compare, and order real numbers by converting them to decimal equivalents or comparing their squared values.

1. Comparison Rules

Positive Numbers: If \(a > b > 0\), then \(\sqrt{a} > \sqrt{b}\). For example, \(67 < 68 \implies \sqrt{67} < \sqrt{68}\).

Negative Reals: On the negative number line, the number with the larger absolute value is smaller: \(-a < -b\) if \(a > b\). For example, since \(\sqrt{149} \approx 12.21 > 11.47\), it follows that \(-11.47 > -\sqrt{149}\).

2. Number Classification

Rational Numbers: Fractions \(\frac{a}{b}\), integers, mixed numbers (e.g., \(-4\frac{5}{12}\), \(-\frac{31}{6}\)), and terminating decimals (\(1.34\)).

Irrational Numbers: Square roots of non-perfect squares (\(\sqrt{37}, \sqrt{145}\)) and powers of transcendental constants (\(-\pi^3, -\pi^2\)).

3. Absolute Values

The absolute value \(|x|\) denotes distance from zero on the real number line:

\[|x| = x \text{ if } x \ge 0, \quad |x| = -x \text{ if } x < 0\]

Example: \(|-1.\overline{345}| = 1.\overline{345} \approx 1.345\).

4. Practical Radical Applications

When physical formulas produce radical quantities like speed \(v = \sqrt{\frac{64}{5}}\text{ m/s}\):

\[\sqrt{\frac{64}{5}} = \frac{8}{\sqrt{5}} = \frac{8\sqrt{5}}{5} \approx 3.58\text{ m/s}\]

Comparing with \(4\text{ m/s}\): \(4 = \sqrt{16} = \sqrt{\frac{80}{5}} > \sqrt{\frac{64}{5}}\).
